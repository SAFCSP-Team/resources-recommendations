# Architecture

Computer architecture is the design and structure of a computer's hardware and systems. It focuses on how different components like the CPU, memory, and input/output devices work together to execute instructions and process data.


## Books

01. [Essentials of Computer Architecture](https://www.amazon.sa/-/en/Essentials-Computer-Architecture-Douglas-Comer/dp/1032727195)
- This book covers the three key aspects of architecture: processors, physical and virtual memories, and input-output (I/O) systems.

02. [Assembly Programming and Computer Architecture for Software Engineers](https://www.amazon.com/Assembly-Programming-Computer-Architecture-Engineers/dp/1943153329)
- This book provides a practical introduction to Assembly programming and computer architecture, focusing on the "why" and "how" behind core concepts. 

03. [Assembly Language for x86 Processors (Kip Irvine)](https://www.amazon.sa/-/en/Assembly-Language-X86-Processors-Irvine/dp/0133769402)

- This book simplifies complex concepts with clear examples and exercises while providing practical insights into writing and debugging machine-level programs.

## Repository

1. [Assembly Language Content](https://github.com/SAFCSP-Team/assembly-language-bootcamp)
- This repository is a comprehensive resource for learning and referencing x86 Assembly Language. It provides detailed content and examples on essential topics such as instructions, registers, flags, and control flow.
