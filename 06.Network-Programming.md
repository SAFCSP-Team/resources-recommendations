# Network Programming

The process of writing programs that communicate with each other over a computer network, using code, libraries, and protocols to send and receive data.

## Books
1. [The TCP/IP Guide: A Comprehensive, Illustrated Internet Protocols Reference](https://www.amazon.sa/TCP-Guide-Comprehensive-Illustrated-Protocols/dp/159327047X)
- This book provides a detailed explanation of the TCP/IP protocol suite, which is the foundation of modern networking and the internet.
2. [The Definitive Guide to Linux Network Programming](https://www.amazon.sa/-/en/Definitive-Guide-Linux-Network-Programming/dp/1590593227)
- The Definitive Guide to Linux Network Programming offers a clear, concise treatment of creating clients and servers under the Linux operating system.
